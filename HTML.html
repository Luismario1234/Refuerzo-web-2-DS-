Maquetacion

HTML

La maquetación en HTML es la base de cualquier sitio web; consiste en organizar y estructurar el contenido mediante "cajas" para que el navegador sepa dónde colocar cada elemento. Actualmente, se utiliza HTML5 semántico, que emplea etiquetas con significado propio para que tanto los buscadores como las tecnologías de asistencia entiendan la jerarquía del sitio. Las etiquetas fundamentales son:

Contenedores de bloque (ocupan todo el ancho disponible) • div — el contenedor genérico más usado, sin significado semántico
• section — agrupa contenido temáticamente relacionado
• article — contenido independiente y autónomo (post, noticia)
• aside— contenido secundario o complementario (barra lateral)
• header — encabezado de la página o sección
• footer — pie de página o sección
• nav — menú o enlaces de navegación
• main — contenido principal del documento (solo uno por página)
• figure / figcaption — imagen con su descripción

La maquetación web se basa en elegir el contenedor adecuado según su propósito y significado. Los contenedores de bloque, como "di", "section", "article" y "main", estructuran las grandes áreas de la página ocupando todo el ancho, mientras que los contenedores en línea como "span" o "a" se ajustan solo a su contenido. El uso de etiquetas semánticas (como "nav" para menús o "header" para encabezados) es fundamental, ya que mejora la accesibilidad y el SEO, dejando los "div" exclusivamente para fines estéticos.

Dentro de estos contenedores, las listas son esenciales para organizar información. La lista desordenada ("ul") se utiliza mediante viñetas cuando el orden de los elementos no es relevante, como en una lista de ingredientes. Por el contrario, la lista ordenada ("ol") se emplea cuando existe una secuencia lógica o jerarquía, como en un paso a paso o un ranking. Las listas ordenadas ofrecen mayor flexibilidad gracias a atributos como type (para cambiar a letras o números romanos), start (para iniciar en un número específico) o reversed (para cuentas regresivas). En ambos casos, cada ítem se define siempre con la etiqueta "li".

Finalmente, para estructuras más complejas, contamos con tablas ("table"), formularios ("form") y elementos de agrupación específica como "figure" para imágenes con leyenda. Elegir el elemento correcto no solo organiza visualmente el sitio, sino que le otorga sentido estructural al código.

Es importante recordar que el HTML solo crea la estructura (el "esqueleto"). Para que esa estructura se vea atractiva y tenga un diseño visual (colores, columnas, espacios), se debe complementar obligatoriamente con CSS.
