Acerca de

maquetación

JAVA

La maquetación en Java es el proceso de organizar los elementos visuales (botones, etiquetas, campos de texto) dentro de una ventana. A diferencia de otros lenguajes donde puedes arrastrar y soltar elementos en una posición fija, Java utiliza Layout Managers (Gestores de Diseño) para que la interfaz sea flexible y se adapte a diferentes tamaños de pantalla.

Comandos de Terminal (JDK)

javac: Compila el código (.java a .class).
java: Ejecuta el programa.
java -version: Muestra la versión instalada.

Tipos de Datos Comunes

int: Números enteros.
double: Números con decimales.
boolean: Valores de verdadero o falso.
String: Cadenas de texto.

Estructuras de Control y Lógica

Entrada/Salida: Se usa System.out.println para mostrar mensajes y la clase Scanner para leer lo que el usuario escribe.
Condicionales (if/else): Toman decisiones según una condición.
Bucles (for/while): Repiten una acción varias veces.
