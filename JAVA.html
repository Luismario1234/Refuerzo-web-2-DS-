La maquetación

Es el proceso de organizar y estructurar los elementos visuales de una página web. Imagina que estás construyendo una casa: el HTML es el plano y los ladrillos que definen dónde va cada habitación, mientras que el CSS es el diseño de interiores que decide el tamaño de los espacios, los colores y la posición exacta de los muebles.

El esqueleto: HTML
HTML (HyperText Markup Language) se encarga de la estructura semántica. No se trata de cómo se ve, sino de qué es cada cosa. Para maquetar, usamos etiquetas que dividen el contenido:
• header: El encabezado o menú superior.
• main: El contenido principal.
• section y article: Para agrupar bloques de información.
• footer: El pie de página.
• div: Un contenedor genérico (se usa cuando no hay una etiqueta semántica específica).

El diseño: CSS

CSS (Cascading Style Sheets) es el que realmente "maqueta". Toma esos bloques de HTML y los posiciona en la pantalla. A lo largo de los años, las técnicas han evolucionado:

Métodos modernos de maquetación:

1. Flexbox (Unidimensional): Ideal para alinear elementos en una fila o una columna. Es perfecto para menús de navegación o centrar cosas
2. CSS Grid (Bidimensional): Es el estándar de oro actual. Permite crear rejillas complejas con filas y columnas simultáneamente, dándote control total sobre el diseño.
3. El concepto de "Responsive Design"
