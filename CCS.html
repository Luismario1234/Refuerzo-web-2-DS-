Maquetacion

CCS

El proceso de maquetación web se define como la organización y estructura de los elementos visuales de una página, donde el HTML actúa como el esqueleto semántico (definiendo qué es cada cosa) y el CSS funciona como el diseño de interiores (controlando colores, tamaños y posiciones)

Conceptos básicos de diseño con CSS

Para maquetar, CSS utiliza reglas que seleccionan un elemento y le dan propiedades. Aquí tienes lo esencial para empezar:
Selectores: Indican a qué elemento aplicar el cambio (ej. header, nav, .clase, #id).
El Modelo de Caja (Box Model): Todo en la web es una caja. Controlas su tamaño con width (ancho) y height (alto), y su espacio con margin (espacio exterior) y padding (espacio interior).
Colores y Fuentes: Propiedades como background-color para el fondo, color para el texto y font-family para la tipografía.
Posicionamiento (Flexbox/Grid): Son herramientas modernas de CSS para alinear elementos fácilmente, como poner dos columnas una al lado de la otra o centrar un menú.

border-box: Mediante la propiedad box-sizing: border-box;, haces que el contenedor no crezca de tamaño cuando le añades rellenos (padding) o bordes, algo vital para que tu diseño no se rompa.

overflow: Define qué pasa si el contenido es más grande que el contenedor (puedes ocultarlo con hidden o añadir barras de desplazamiento con scroll).

::before y ::after: Son contenedores "fantasma" que creas desde CSS para añadir elementos decorativos (como iconos o líneas) sin tener que escribir más código en el HTML.

El Modelo de Caja (Box Model)

Todo elemento en HTML es una caja rectangular compuesta por cuatro capas esenciales que determinan su tamaño y espacio: Content (el contenido real), Padding (espacio interior), Border (el borde) y Margin (espacio exterior fuera del borde) (pp. 3-4).

Métodos de Posicionamiento Modernos

Flexbox (Unidimensional): Se especializa en alinear elementos en una sola dirección (fila o columna). Es ideal para componentes pequeños como barras de navegación o para centrar elementos perfectamente (pp. 4, 10).

CSS Grid (Bidimensional): Es el estándar para crear rejillas complejas que manejan filas y columnas simultáneamente. Se utiliza principalmente para el layout general de la página o galerías de imágenes (pp. 4, 10).
